# Upstream attribution

This is a compatibility repair for [ComfyUI-LJNodes](https://github.com/coolzilj/ComfyUI-LJNodes), not a standalone custom-node pack. Install the original package first.

The helper and original backup derive from ComfyUI-LJNodes commit `8172f7221071bc9b04e0230aed7648944c62c350`, copyright (c) 2024 Jin Liu, distributed under the included MIT license.

Related upstream report: [issue #16](https://github.com/coolzilj/ComfyUI-LJNodes/issues/16).

The supplied `ui_helpers.zip` is the installation download. Back up your own installed helper before overwriting it, particularly if it differs from the version described above. The bundled backup restores the exact version used to develop this repair, not any additional local changes you may have made.

The workspace path in the README describes the developer's local staging copy; other users do not need that directory. Keep the archive or a separate backup instead.
